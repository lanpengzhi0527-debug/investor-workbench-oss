# Public-Core Provenance

Investor Workbench OSS is a clean public-core extraction derived from audited product behavior, not a publication of a private deployment or its Git history.

## Behavior retained in the public core

- local-first, read-only workspace shell
- portfolio, research, decision, data-health, and agent-control concepts
- evidence and source-health concepts
- escaped research rendering
- default-deny agent safety boundary
- guarded validation workflow

## Rebuilt for public use

- application logic is organized as small public modules
- the reference adapter uses synthetic fixtures only
- release scanners enforce the public/private data boundary
- browser validation runs offline against synthetic fixtures

## Intentionally excluded

- production adapters and credentials
- real account, portfolio, or transaction data
- private research content and metadata
- internal design archives and operational run logs
- private screenshots, backups, and machine-specific paths

The public demo does not require any private repository, private database, credential, or production data source to run.
