# Changelog

## 0.1.0 - 2026-08-12

Initial open-source release of the reusable Investor Workbench core.

### Added

- Local-first research workspace shell
- Synthetic portfolio and research fixtures
- Escaped research renderer
- Source-health summary
- Default-deny agent capability policy
- Public-boundary and independent release scans
- Guarded Git validation workflow
- Chromium-based browser smoke test
- Architecture, security, contribution, and private-to-public release-gate documentation

### Explicitly excluded

- Real account, portfolio, and transaction data
- Private research archives and production adapters
- Trade execution
- Credentials and private API configuration
- Internal design-authority archives and operational run logs
